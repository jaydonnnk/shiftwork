to be replaced by typed objects through re-authoring and sealing. The current family is already
OPERATOR_SEALED, and rotation.variant_ref hashes expected and stimulus content.
That rewrite would change six identities used by exposure records, so simply
re-sealing the converted bytes can treat previously exposed content as fresh.
This conflicts with preserving Board 1 and its exposure/history boundaries.

Re-approved correction: preserve the exact existing Bellwether sealed payloads,
seals, stored snapshots and variant refs. Decode only those six pinned legacy
payloads to typed acceptance views for assessment. The decoded view never
replaces the identity-bearing case or persisted payload. Require typed aspects
for Northline, GTM and future authored cases. Unknown strings, altered legacy
payloads and cross-pack use fail before exposure. Caller input never enables
legacy decoding. Gate 3 was explicitly RE-APPROVED for this scope on 2026-10-03;
Gate 4's approved slice order remains intact and S22a implementation is authorized.
