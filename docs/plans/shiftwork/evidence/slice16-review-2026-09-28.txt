4. Proof for finding R3: unmeasured usage is reported as a measured zero
------------------------------------------------------------------------

=== PROOF 2: a run with no recorded model observation reports measured zeros ===
  status=COMPLETE service_calls=0
  input_tokens=0 output_tokens=0 service_latency_ms=0
  cost_minor_units=None provisioning_latency_ms=None
  two efficiency fields say 'unknown' (None); three assert a measured 0
  for a run where nothing was instrumented.

`_known_sum(values, 0)` returns `sum([]) == 0`, so a slot with no
`INFERENCE_REQUEST` observation reports 0 calls, 0 tokens and 0 ms. The
trusted-local executor records no observation at all, so this is the value the
offline demo and every route test project. The Compare card note rendered by
`shiftwork/client/app.js` states "Unknown usage or cost is never treated as
zero" while the same card prints `0` for three of the five efficiency fields.

The same code path changes an eligibility verdict once a frozen budget makes
a metric mandatory:

=== PROOF 3: an uninstrumented candidate passes a mandatory budget a measured one fails ===
  candidate A: eligible=False blockers=('mandatory_budget_exceeded:service_calls',)
  candidate B: eligible=True blockers=()
  A recorded one real model call and is blocked; B recorded nothing and is eligible.

Both candidates are otherwise identical and complete. The current draft
comparison freezes no `mandatory_budget_metrics`, so this arm is latent today
and the displayed-zero arm is live today.
