Reconsider, without rewriting

No automatic switch. A new operating choice requires a new explicit selection of an exact tested version and a new rationale. This input and this experiment change neither the original choice nor any incident or ledger.

Exact execution mechanisms and scoring methodology are deferred to later gates. There is no implemented restart, hidden-case run or learning evidence in this mockup.
